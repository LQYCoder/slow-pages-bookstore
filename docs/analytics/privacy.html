READING, WITH RESPECT

关于这里的访问统计。

我们希望知道哪些故事被翻开、被读了多久，用来改进阅读体验。

正在读取统计设置。

记录什么

启用后记录访问开始时间、页面、前台停留时长、估算阅读时长、动态观看时长， 以及服务端根据 IP 推断的国家、省州和城市。本站数据库不保存原始 IP。

每日随机浏览器标识用于当天访客去重，服务端按日做不可直接还原的匿名化。 不采集你的摘句、书签内容、表单输入、私人录音或浏览器指纹，也不请求精确位置。

数字的边界

切到后台或窗口失去焦点后停止计时。阅读时间还要求正文在视口内， 且最近 60 秒有操作；它是行为估计，不代表真正读懂了多少。

IP 地区可能是运营商或代理的出口地址。不同设备、隐私模式及清除浏览器数据会影响访客去重。 拦截统计、断网或离开页面时补报失败会少计。

由谁处理与保留

启用时，统计由 Cloudflare Workers 接收，存入独立的 Cloudflare D1 数据库。 阅读页面继续在 GitHub Pages 托管。 访问明细只允许持有管理密钥的人查看，默认保留 90 天后自动删除。 启用后的服务地址会显示在下方。

你可以不参与

本站尊重浏览器的 Do Not Track 和 Global Privacy Control 信号。 你也可以在此关闭本浏览器的统计，阅读、书签和夜读功能仍然可用。

关闭只影响之后的上报；不删除此前已汇总的匿名记录。
